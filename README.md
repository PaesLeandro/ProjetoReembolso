# Projeto Sistema de Reembolso

Aplicacao web simples para registrar despesas e calcular o total de solicitacoes de reembolso.

## Funcionalidades

- Cadastro de despesa com nome, categoria e valor
- Formatacao automatica do valor em BRL
- Listagem de despesas
- Atualizacao de quantidade e total
- Remocao de despesa da lista

## Estrutura

- index.html: estrutura da pagina
- styles.css: estilos da interface
- scripts.js: logica de formulario, lista, totais e remocao
- img/: icones e assets visuais

## Como executar

1. Abra o arquivo index.html no navegador.
2. Preencha os campos do formulario e clique em Adicionar despesa.
3. Acompanhe a lista, quantidade e total no painel lateral.
